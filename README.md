# PMC 系统（生产物料控制）

> 面向大中型公司的 PMC 系统：采购、库存、生产、BOM、MRP。
> 全中文，中文注释 + 大白话解释。匹配中国市场、中国工厂习惯，支持 Excel / WPS 导入导出。

## PMC 是什么

PMC = Production Material Control（生产物料控制）。

大白话：公司里专门管“要生产什么、缺什么料、什么时候买料、买多少”的环节。

核心链路：订单 → 排生产计划 → 查 BOM 算缺料 → 生成采购需求 → 采购 → 入库 → 生产 → 财务对账

- BOM（物料清单，大白话就是配方表）：做一个成品要哪些零件、每个要几个
- MRP（物料需求计划，大白话就是自动算缺啥料、买多少）：净需求 = 毛需求 - 可用库存 - 在途 + 安全库存

## 目录结构

- `PMC系统方案.md`：完整方案（选型、架构、模块、实施计划）。先读它。
- `mvp/`：MVP（最小验证法，大白话就是先做最小的、能证明核心能跑通的版本）。例子：小夜灯 100 个 → MRP → 采购含税 1380.86 → 到货入库 → 生产 → 成品 100。含验证报告。
- `phase1/`：第一阶段完整版。BOM 多版本/对比/多层爆炸+循环检测、库存调拨/盘点/批次追溯、供应商比价、采购申请审批、MRP 手动调整、看板、Excel 导入导出。验证脚本 128 项通过。
- `phase2/`：第二阶段。逐级领料修复（半成品不再虚增）、按批次冻结、数据库序列单号、多公司/多仓库/多币种、金额分级审批、财务对账、权限 RBAC、报表+审计。验证脚本 176 项通过。
- `phase3/`：第三阶段（智能 + 落地收尾）。智能补货建议（再订货点公式）、供应商自动比价 + 自动推荐（按推荐供应商分组生成采购单）、助手查询（关键词 + 规则解析，不用大模型猜）、移动端适配、登录（Token，替代演示身份 X-User）、模拟表单（3 个模板 + 1 份已填好数据）+ 《怎么用.md》。验证脚本 133 项通过。**推荐从这里开始用，见 `phase3/怎么用.md`。**
  - 2026-10-20 第四轮迭代（按用户定的业务定义落地）：仓库默认库位 + 日期批次（P1-5）、入库表/出库表 Excel 导出 + 字段字典 `phase3/字段字典.md`（P2-5）、领料部门/用途（选填）+ 在制不算可用 + 齐套看板（P2-6）；P1-9 服务端强制改密按用户决定选 B 关闭（只提示不强制）。新增回归测试 `phase3/backend/test_p2_round2.py` 31 项通过。

## Excel / WPS 适配

- 公司真正用的时候很多数据都在 Excel 里记。系统支持 `.xlsx` 导入导出，零件、库存、采购单等能从 Excel 搬进来，也能导出来。
- Excel 表格每个公司都不一样，导入支持灵活映射：物料编码 / 材料编码 / 料号 / 零件编码都能映射到零件编码，导入时校验并提示行号。
- WPS 兼容：用 `.xlsx` 通用格式。

## 中国市场适配

- 中文界面、中文表头、中文报错
- 税率默认 13%，含税 / 未税分开算
- 库位、批次、五表一字典思路（采购表、入库表、出库表、库存结存表、供应商对账表）
- 通用、可复刻，不绑定某一家公司
